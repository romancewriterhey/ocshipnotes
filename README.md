# 現代背景 OC／CP 設定手帳

一個給現代背景原創角色（OC）與原創 CP 創作者使用的免費網頁工具，無任何營利。

## 功能
- 人物設定：基本資料、個性、身心狀態、家庭、戀愛經驗，可上傳頭貼、立繪與圖庫
- 人物深化：原創角色分析單，一次五題，可鎖定或重骰，回答存成深化筆記
- CP設定：二到六人的 CP 彙整，以及不同認識程度的互動模式
- 人物關係表：帶入人物或 CP，拖曳排版、換代表色、新增旁支人物
- 時間軸：一鍵帶入出生年與認識、交往、結婚年份，自動計算當時年齡
- 短文練習題：三十題、五十題題庫隨機抽五題
- 人事時地物產生器：依地區、調性與場域抽出完整場景與梗，情境卡可排成劇情大綱
- 劇情大綱：可切換「簡要大綱」（自由書寫、起承轉合、三幕劇、感情線五階段）與「章節細綱」；手動整理或整份貼上大綱，可改字色（人物代表色）與字級，輸出文字檔或 PDF
- 伏筆追蹤：記錄伏筆埋在哪段、在哪回收，提醒未回收的伏筆
- 寫作進度：目標字數、截稿日、每日字數、連續寫作天數與 30 天長條圖
- 出版企劃：自動帶入人物與大綱，整理成投稿用企劃書（PDF／文字檔），並記錄投稿狀態與投稿要求清單
- 作品分組：切換作品後各頁只顯示該作品內容，可一鍵匯出整份設定集
- 故事正文年份：自動換算人物在正文當年的年齡
- 備份提醒：太久沒備份時會在頁面上方提醒

所有內容只存在使用者自己的瀏覽器，本工具不蒐集任何資料。

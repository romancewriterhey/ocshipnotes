# 現代背景 OC／CP 設定手帳

一個給現代背景原創角色（OC）與原創 CP 創作者使用的免費網頁工具，無任何營利。

## 功能
- 人物設定：基本資料、個性、身心狀態、家庭、戀愛經驗，可上傳頭貼、立繪與圖庫
- 人物深化：原創角色分析單，一次五題，可鎖定或重骰，回答存成深化筆記
- CP設定：二到六人的 CP 彙整，以及不同認識程度的互動模式
- 人物關係表：帶入人物或 CP，拖曳排版、換代表色、新增旁支人物
- 時間軸：一鍵帶入出生年與認識、交往、結婚年份，自動計算當時年齡
- 短文練習題：三十題、五十題題庫隨機抽五題
- 人事時地物產生器：依地區、調性與場域抽出完整場景與梗

所有內容只存在使用者自己的瀏覽器，本工具不蒐集任何資料。
